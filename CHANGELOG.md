# Changelog

## 1.0.0 (2026-10-23)

First public release.

- `review.py`: one command for the full review, with ten annotated images, `report.md` (scorecard, fix first,
  consider, details), `fix-brief.md` for an agent and a designer, and `findings.json` for before and after
  comparisons with `--baseline`.
- Measurements: construction grid, alignment, stroke weights from fitted circles, gaps between facing edges,
  rings, arcs and shared centres, radius system, angle system, symmetry, balance, small sizes, complexity.
- Colour: contrast on six standard backgrounds and brand backgrounds, same-hue lighter and darker versions, colour
  vision simulation and greyscale.
- References: what a senior designer checks, construction rules, colour, fixing methods, prompts and briefs,
  writing the review, how the measurements work.
- Demo mark with six known faults, sample reviews, regression test, Claude Code plugin and marketplace manifests.
